# 기능 요구사항

- `content-definitions`: 콘텐츠 정의 문서
- `gameplay`: 상호작용/게임플레이 요구사항
- `traceability`: 요구사항-구현 정합성 및 커버리지
- `ui`: UI 요구사항 문서
- `scenario`: 시나리오 실행/이벤트/검증 기능 요구사항
- `registry`: 레지스트리/프리로드/웨이포인트 기능 요구사항
- `player`: 플레이어/인벤토리/태그 기능 요구사항
- `item`: 아이템 시스템 및 트리아지 아이템 정의 요구사항
- `interaction`: 인터랙터블 시스템 요구사항
- `chat-command`: 채팅/커맨드 기능 요구사항
- `datapack`: 데이터팩 런타임 요구사항
- `quest`: 퀘스트 기능 요구사항
- `session`: LAN 세션 기능 요구사항
- `patient`: 환자 모니터/환자 모델 요구사항
- `module-features`: 기능 문서 작성 가이드 및 TODO

모듈 차이는 각 문서의 front matter `domain` 값으로 구분합니다.
- `module-features.multiplayer-infrastructure`
- `module-features.triage-trainer`
