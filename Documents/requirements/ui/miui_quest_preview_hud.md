# 퀘스트 프리뷰 HUD UI

| 항목 | 내용 |
| :-: | :-: |
| ID | (`miui_quest_preview_hud`) |
| 깊이 | 0 |
| (*깊이 1인 경우), 다른 깊이 1의 UI 대체 표시 가능 여부 | 해당없음 |
| 진입 시 마우스 잠금 | 잠금 |
| 진입조건 | - 시작 시 자동 초기화 후 추적 퀘스트가 있으면 HUD 갱신 |
| 탈출조건 | - 없음. 코드로 제어 |

## 개요

현재 추적 중인 퀘스트 요약을 상시 HUD로 표시합니다. (`Y` 키로 웨이포인트 하이라이트 호출)

## 상세

퀘스트 프리뷰 HUD는 `QuestPreviewHudUIController`가 `QuestManager`의 추적 목록 변화를 구독하여 요약 정보를 표시합니다. 퀘스트 패널과 달리 화면을 가리지 않는 깊이 0 정보성 UI입니다.

추적 목록에 포함된 웨이포인트 식별자는 내부 캐시에 유지되며, 사용자가 `Y` 키를 누르면 각 웨이포인트 앵커의 하이라이트를 순차 호출합니다.

오버레이 스택과 무관하게 항상 표시 가능한 상태를 유지하되, 추적 대상이 없으면 표시 정보는 최소화됩니다.
