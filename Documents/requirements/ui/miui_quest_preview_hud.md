# 퀘스트 프리뷰 HUD UI

| 항목 | 내용 |
| :-: | :-: |
| ID | (`miui_quest_preview_hud`) |
| 깊이 | 0 |
| (*깊이 1인 경우), 다른 깊이 1의 UI 대체 표시 가능 여부 | 해당없음 |
| 진입 시 마우스 잠금 | 잠금 |
| 진입조건 | - 시작 시 자동 초기화 후 추적 퀘스트가 있으면 HUD 갱신 |
| 탈출조건 | - 없음. 코드로 제어 |

## 개요

현재 추적 중인 퀘스트 요약을 상시 HUD로 표시합니다. (`Y` 키로 웨이포인트 하이라이트 호출)

## 상세

퀘스트 프리뷰 HUD는 `QuestPreviewHudUIController`가 `QuestManager`의 추적 목록 변화를 구독하여 요약 정보를 표시합니다. 퀘스트 패널과 달리 화면을 가리지 않는 깊이 0 정보성 UI입니다.

추적 목록에 포함된 웨이포인트 식별자는 내부 캐시에 유지되며, 사용자가 `Y` 키를 누르면 각 웨이포인트 앵커의 하이라이트를 순차 호출합니다.

오버레이 스택과 무관하게 항상 표시 가능한 상태를 유지하되, 추적 대상이 없으면 표시 정보는 최소화됩니다.

## 함께 완료해야 넘어가는 임무의 대기 표시

서로 다른 참여자 두 명 이상에게 분기를 배정한 `waitMode: All` 병렬 노드는 모든 참여자가 자기 분기를 끝내야 다음 노드로 넘어갑니다. 서버는 이 구간의 참여자별 완료 여부와 각 분기가 발행한 퀘스트 식별자를 `ScenarioGroupGateTracker`로 집계하여 `ScenarioGroupGateSnapshot`으로 전달하고, 클라이언트의 `ScenarioGroupGateState`가 이를 보관합니다. `QuestManager`는 스냅샷을 내보낼 때 로컬 참여자의 분기가 발행한 퀘스트에 그 상태를 `QuestData.GroupWait`로 붙입니다.

- 내 몫은 끝났는데 아직 끝내지 않은 참여자가 남아 있으면, 카드의 현재 목표 줄에 `다른 플레이어가 완료할 때까지 기다리기(n/N)`을 표시합니다. n은 자기 몫을 끝낸 참여자 수(접속이 끊겨 분기가 취소된 참여자 포함)이고, N은 이 병렬 노드에 배정된 참여자 수입니다.
- 분기가 발행한 퀘스트가 분기 안에서 모두 회수되어 대기 상태를 실을 퀘스트가 없으면, `QuestManager`가 `다른 플레이어 기다리기` 자리 표시 퀘스트를 추적 목록 맨 앞에 합성합니다. 따라서 기다리는 동안 HUD에는 항상 대기 카드가 남습니다.
- 대기 문구의 숫자만 바뀌는 갱신에는 목표 달성 취소선 연출을 적용하지 않습니다.
- 마지막 참여자가 끝나면 서버가 닫힘 스냅샷(`active: false`)을 보내 대기 표시가 사라지고, 시나리오가 종료되거나 수동 진입으로 중단될 때에도 같은 방식으로 정리됩니다.
