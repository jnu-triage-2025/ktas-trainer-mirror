# 상호작용 힌트 UI

| 항목 | 내용 |
| :-: | :-: |
| ID | (`miui_interactable_hint`) |
| 깊이 | 0 |
| (*깊이 1인 경우), 다른 깊이 1의 UI 대체 표시 가능 여부 | 해당없음 |
| 진입 시 마우스 잠금 | 잠금 |
| 진입조건 | - 로컬 플레이어 시작 후 주변 상호작용 목록 갱신 시 표시 데이터 업데이트 |
| 탈출조건 | - 없음. 코드로 제어 (목록 비움/모드 전환) |

## 개요

근처 상호작용 가능 대상 목록과 현재 선택 항목을 표시하는 HUD UI입니다.

## 상세

이 UI는 `InteractableObjectHintUIController`가 주변 탐지 결과를 받아 목록 형태로 렌더링합니다. 플레이어는 스크롤/보조 키 입력으로 선택 항목을 이동하고, 선택된 항목에 대해 상호작용을 실행합니다.

일반 모드에서는 월드 상호작용 후보를 표시하고, 다이얼로그 모드에서는 선택지 전용 목록으로 전환됩니다. 다이얼로그 모드 진입 시 기존 목록을 캐시하고, 종료 시 복원하여 맥락 전환을 보장합니다.

깊이 0 HUD로 동작하므로 마우스 잠금 상태를 변경하지 않으며, 오버레이 스택 관리 대상이 아닙니다.
