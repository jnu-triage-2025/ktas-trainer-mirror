# (UI명)

| 항목 | 내용 |
| :-: | :-: |
| ID | (`namespace:ui_identifier`) |
| 깊이 | 1 |
| (*깊이 1인 경우), 다른 깊이 1의 UI 대체 표시 가능 여부 | 불가 |
| 진입 시 마우스 잠금 | 해제 |
| 진입조건 |
| 탈출조건 |

<!-- 
  사용 가능 예시

  깊이: 
  - HUD 형태로 표시, 십자선 등은 0임
  - 오버레이되어 마우스 잠금이 해제되는 경우 대개는 1임

  진입 시 마우스 잠금: 해제, 잠금

    - 시나리오 그래프 `??`에 의해 진입
    - `??`와 상호작용 시 진입

  탈출조건:
  - 키보드 `esc` 입력
  - 키보드 `??` 입력
  - 없음. 코드로 제어
