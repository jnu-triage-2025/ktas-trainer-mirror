# 핫바 UI

| 항목 | 내용 |
| :-: | :-: |
| ID | (`miui_hotbar`) |
| 깊이 | 0 |
| (*깊이 1인 경우), 다른 깊이 1의 UI 대체 표시 가능 여부 | 해당없음 |
| 진입 시 마우스 잠금 | 잠금 |
| 진입조건 | - 로컬 플레이어 시작 시 `SetupHotbarUI()` 실행 |
| 탈출조건 | - 없음. 코드로 제어 |

## 개요

인벤토리 슬롯의 선택 상태를 하단 HUD로 표시하고 숫자키/휠 입력과 연동하는 UI입니다.

## 상세

핫바 UI는 `HotbarUIController`가 시작 시 슬롯 개수를 초기화하고 인벤토리 바인딩을 수행합니다. 선택 슬롯 정보는 HUD에 즉시 반영되며, 인벤토리 변경 이벤트와 동기화됩니다.

플레이어 입력 계층에서 숫자키(`1`~`9`) 또는 마우스 휠 입력이 들어오면 선택 슬롯을 이동합니다. 상호작용 대상이 가까운 경우 일부 휠 입력이 상호작용 선택으로 우선 처리될 수 있습니다.

깊이 0 HUD이므로 별도 진입/탈출 상태를 갖지 않고, 오버레이 스택에도 포함되지 않습니다.
