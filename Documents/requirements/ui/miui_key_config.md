# 키 설정 UI

| 항목 | 내용 |
| :-: | :-: |
| ID | (`miui_key_config`) |
| 깊이 | 2 |
| (*깊이 1인 경우), 다른 깊이 1의 UI 대체 표시 가능 여부 | 해당없음 |
| 진입 시 마우스 잠금 | 해제 |
| 진입조건 | - ESC 메뉴의 `Key Config` 버튼 클릭<br>- 이 `id`로 UI를 쿼리하여 오버레이 스택 push |
| 탈출조건 | - 키보드 `Esc` 입력으로 오버레이 스택 pop<br>- `Close` 버튼 클릭 |

## 개요

키 바인딩 조회/리바인딩/초기화 기능을 제공하는 설정 오버레이 UI입니다.

## 상세

키 설정 UI는 `KeyConfigUIController`가 액션 목록과 키보드 레이아웃을 동기화해 보여줍니다. 항목을 선택하면 대응 키가 강조되고, 리바인딩 모드에서 입력된 새 키를 바인딩으로 저장합니다.

리바인딩 결과는 저장소(PlayerPrefs 경로)로 즉시 반영되며, `Reset` 동작으로 기본값 복원이 가능합니다. 리바인딩 대기 중 `Esc` 입력은 바인딩 적용이 아니라 대기 취소로 우선 처리됩니다.

본 UI는 ESC 메뉴 위에 중첩되는 깊이 2 오버레이이며, 닫히면 상위 ESC 메뉴 컨텍스트로 복귀합니다.
