# 인벤토리 UI

| 항목 | 내용 |
| :-: | :-: |
| ID | (`miui_inventory_panel`) |
| 깊이 | 1 |
| (*깊이 1인 경우), 다른 깊이 1의 UI 대체 표시 가능 여부 | 불가 |
| 진입 시 마우스 잠금 | 해제 |
| 진입조건 | - 키보드 `E` 입력으로 토글<br>- 이 `id`로 UI를 쿼리하여 오버레이 스택 push |
| 탈출조건 | - 키보드 `E` 재입력으로 토글 닫기<br>- 키보드 `Esc` 입력으로 오버레이 스택 pop |

## 개요

아이템 슬롯 조회/이동/드롭을 수행하는 오버레이 UI입니다.

## 상세

인벤토리 UI는 `InventoryUIController`가 오버레이 push/pop 이벤트에 따라 열림/닫힘을 관리합니다. 열릴 때 플레이어는 UI 오버레이 모드로 전환되어 시점 조작이 제한되고 커서 입력이 활성화됩니다.

슬롯 뷰는 드래그/이동/정렬 등의 사용자 조작을 처리하며, 닫힐 때 들고 있던 아이템을 인벤토리로 자동 복귀시켜 상태 불일치를 방지합니다. UI 내에서 바깥으로 드롭된 아이템은 플레이어 전방 드롭 로직으로 전달됩니다.

핫바와의 동기화 이벤트를 통해 선택 슬롯 상태와 아이템 표현이 함께 갱신됩니다.
