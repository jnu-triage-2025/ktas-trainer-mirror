# 채팅 UI

| 항목 | 내용 |
| :-: | :-: |
| ID | (`miui_chat_panel`) |
| 깊이 | 1 |
| (*깊이 1인 경우), 다른 깊이 1의 UI 대체 표시 가능 여부 | 불가 |
| 진입 시 마우스 잠금 | 해제 |
| 진입조건 | - 키보드 `T` 입력<br>- 키보드 `/` 입력 (명령어 프리픽스 시작)<br>- 이 `id`로 UI를 쿼리하여 `Open()` 호출 |
| 탈출조건 | - 키보드 `Enter` 입력으로 전송 후 닫힘<br>- 키보드 `Esc` 입력으로 취소 후 닫힘<br>- 키보드 `Esc` 입력으로 오버레이 스택 pop |

## 개요

텍스트 채팅/명령어 입력과 최근 메시지 로그(토스트 포함)를 제공하는 오버레이 UI입니다.

## 상세

채팅 UI는 `ChatUIController`가 `UIOverlayStack`에 push/pop되면서 열림/닫힘 상태를 관리합니다. 열릴 때 입력 포커스를 강제로 가져오고, 로그 토스트를 정리하며 플레이어를 UI 오버레이 모드로 전환합니다.

`T` 입력은 일반 채팅 모드, `/` 입력은 명령어 프리픽스가 삽입된 상태로 진입합니다. 열린 상태에서 `Enter`를 누르면 현재 입력이 소비되어 제출 이벤트가 발생하고 즉시 닫힙니다. `Esc`를 누르면 취소 이벤트를 발생시킨 뒤 닫힙니다.

패널이 닫히면 입력 버퍼를 비우고 플레이어의 오버레이 모드를 해제합니다. 메시지 수신 시에는 패널이 닫혀 있어도 토스트를 통해 최근 메시지를 확인할 수 있습니다.
