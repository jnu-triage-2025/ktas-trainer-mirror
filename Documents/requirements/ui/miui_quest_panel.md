# 퀘스트 패널 UI

| 항목 | 내용 |
| :-: | :-: |
| ID | (`miui_quest_panel`) |
| 깊이 | 1 |
| (*깊이 1인 경우), 다른 깊이 1의 UI 대체 표시 가능 여부 | 불가 |
| 진입 시 마우스 잠금 | 해제 |
| 진입조건 | - 키보드 `J` 입력으로 토글<br>- 이 `id`로 UI를 쿼리하여 `Open()` 또는 오버레이 스택 push |
| 탈출조건 | - 키보드 `J` 재입력으로 토글 닫기<br>- 키보드 `Esc` 입력으로 오버레이 스택 pop |

## 개요

퀘스트 목록과 추적 상태를 확인하고 변경하는 오버레이 UI입니다. 화면 전체를 덮는 딤 배경 위에 저널 형태의 창 하나를 띄우고, 창 내부를 좌우 두 단으로 나누어 왼쪽에는 임무 목록을, 오른쪽에는 선택한 임무의 상세 내용을 표시합니다.

## 화면 구성

- **헤더:** 왼쪽에는 제목과 현재 추적 수(`추적 n/3`)를 표시하고, 가운데에는 목록 필터 탭(`전체`, `진행 중`, `완료`)을 배치하며, 오른쪽에는 `×` 닫기 버튼을 배치합니다. 닫기 버튼은 `J` 키나 `Esc` 키와 동일하게 `UIOverlayStack`을 통해 패널을 닫습니다.
- **왼쪽 목록:** 임무를 `추적 중`, `진행 중`, `완료` 세 분류로 묶어서 표시합니다. 각 항목은 마름모 마커와 임무 제목, 현재 목표 요약, 상태 배지(`추적 중`, `완료`, `고정 불가`)로 구성되며, 항목을 클릭하면 오른쪽 상세 영역이 해당 임무로 전환됩니다. 선택한 항목은 강조 테두리로 구분합니다.
- **오른쪽 상세:** 임무 제목과 부가 정보(진행도, 순차 진행 여부, 웨이포인트)를 먼저 표시하고, 그 아래에 현재 목표를 강조한 줄을 배치합니다. 이어서 임무 설명, 세부 목표 목록, 임무 정보 타일(진행도, 세부 목표, 상태, 범위)을 스크롤 영역에 표시합니다. 세부 목표는 달성 여부를 체크 표시와 취소선으로 구분하고, 순차 진행 임무는 아직 도달하지 않은 목표를 감춥니다.
- **참여자 목록:** 여러 참여자가 함께 끝내야 넘어가는 임무에서는 세부 목표 아래에 `함께 완료해야 하는 참여자 (n/N)` 목록을 표시합니다. 자기 몫을 끝낸 참여자는 취소선과 `완료함`으로(예: `~~플레이어 a~~ 완료함`), 접속이 끊겨 분기가 취소된 참여자는 취소선과 `이탈함`으로 표시하고, 아직 진행 중인 참여자는 이름만 표시합니다. 내 항목에는 `(나)`를 덧붙입니다.
- **고지 배너:** 완료한 임무이거나, 추적 고정을 지원하지 않는 임무이거나, 추적 수가 상한에 도달한 경우에 상세 영역 하단에 안내 문구를 표시합니다. 내 몫은 끝났지만 다른 참여자를 기다리는 임무에서는 그 사실을 알리는 문구를 우선 표시합니다.
- **추적 토글:** 상세 영역 맨 아래의 버튼으로 선택한 임무의 추적 상태를 전환합니다. 완료했거나 고정할 수 없는 임무에서는 버튼이 비활성 상태로 표시됩니다.

## 상세

퀘스트 패널은 `QuestUIController`가 `QuestManager` 이벤트에 연결되어 목록/추적 상태를 실시간 동기화합니다. 열릴 때 오버레이 모드로 전환되어 플레이어 입력이 UI 중심으로 전환됩니다.

상세 영역의 추적 토글은 `QuestManager.SetTracked`로 전달되어 HUD 및 웨이포인트 하이라이트 시스템과 연쇄 동작합니다. 닫힘 시에는 오버레이 모드를 해제하고 기존 플레이 입력 상태를 복원합니다.

`J` 키 토글과 `Esc` pop 모두 `UIOverlayStack`을 통해 동일한 라이프사이클로 처리됩니다.

패널의 시각 스타일은 `QuestPanelUI.uss`에 정의되어 있으며, `ItemSubmissionUI`와 `InventoryUI`에서 사용하는 navy 계열 팔레트를 그대로 따릅니다.

## 함께 완료해야 넘어가는 임무

서로 다른 참여자 두 명 이상에게 분기를 배정한 `waitMode: All` 병렬 노드에 속한 임무는 `QuestData.GroupWait`에 공동 진행 상태(`QuestGroupWaitStatus`)를 갖습니다. 이 상태는 서버가 집계해 내려 준 `ScenarioGroupGateSnapshot`을 `QuestManager`가 로컬 참여자 기준으로 정리한 값입니다.

- 목록 항목의 현재 목표 요약과 상세의 현재 목표 줄은, 내 몫이 끝났고 다른 참여자가 남아 있으면 `다른 플레이어가 완료할 때까지 기다리기(n/N)`을 표시합니다.
- 참여자 목록은 내 몫이 끝나기 전에도 표시되므로, 누가 아직 진행 중인지 미리 확인할 수 있습니다. 참여자 이름은 서버가 `UserDescriptorService`에서 찾은 표시 이름이고, 없으면 역할 태그, 그다음 `플레이어 {클라이언트 번호}`를 사용합니다.
- 임무 정보 타일에는 `참여자 완료` 타일(`n/N`)이 추가되고, 대기 중인 임무의 `상태` 타일은 `대기 중`으로 표시됩니다.
- 분기가 발행한 퀘스트가 모두 회수된 뒤에도 기다리는 중이면 `QuestManager`가 합성한 `다른 플레이어 기다리기` 자리 표시 임무가 `추적 중` 분류에 나타납니다. 이 임무는 추적 고정을 지원하지 않으며 게이트가 열리면 사라집니다.
