## 개요

인트로 씬에서 세션 생성/검색/참여 요청을 구성하는 진입 UI입니다.

## 상세

인트로 UI는 `SceneUIIntroSceneController`가 버튼/입력필드/세션목록을 관리합니다. 사용자는 호스트 생성, LAN 검색 후 참여, 직접 주소 참여의 세 가지 경로 중 하나를 선택할 수 있습니다.

버튼 액션이 실행되면 세션 정보와 런치 의도(호스트/클라이언트, LAN 사용 여부)가 런타임 레지스트리에 저장되고 인게임 씬으로 전환됩니다. 이후 실제 네트워크 시작은 인게임 씬의 시스템이 해당 런치 의도를 읽어 수행합니다.

진입 씬 자체가 UI 중심 화면이므로 마우스는 기본적으로 해제 상태에서 동작합니다.
