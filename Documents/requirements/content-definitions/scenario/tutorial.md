## 튜토리얼 씬

1. 이동
  
미니 퀘스트 오버레이 발생
- 이동하기
- 텍스트 콘텐츠: "wasd 키와 마우스를 사용하여 캐릭터를 이동하세요."
- 기술노트: 이 콘텐츠에 한하여, wasd와 마우스 입력 혹은 플레이어의 이동 자체를 감지해서 다음으로 진행해야 함
- 기술노트: 움직임 감지 시: 미니 퀘스트 오버레이의 콘텐츠를 지우고 "퀘스트 완료" 표시를 띄워야 함. 다만 이러한 연출이 구현되지 않았을 것으로 인식하고 있으므로, 해당 기능에 이 구현을 추가하여야 함 (지시문):
  ```
  미니 퀘스트 오버레이는 발행된 퀘스트들 중 한두개를 미리보기로 화면에 띄울 수 있는 기능으로, 시나리오 노드에도 추가되어있다. 하지만 퀘스트 완료 표시가 나타나지 않고 있고, 퀘스트 display도 덜 구현되어있다. 

  1. 퀘스트 완료 시 1초동안 퀘스트 오버레이의 콘텐츠를 지우고 퀘스트 완료 표시를 띄워야 한다.
  2. 퀘스트에 하위 퀘스트(= 중간 달성 조건)가 있을 수 있다. 여기에 대한 기능이 추가되어있으나, 지나치게 플레이어 친화적이지 않은 것도 있다. 하위 퀘스트에 대해서, DisplayTextContent 기능을 추가하여라(DisplayTextContent가 만약 유효한 텍스트 값이라면, 중간 달성 조건을 기본적으로 지정된 값 대신 DisplayTextContent의 값으로 표시하도록 한다.)
  3. 퀘스트의 중간 달성 조건이 있는 경우, 이 중간 달성 조건을 달성했다면 달성 조건을 취소선을 긋고 녹색 텍스트로 표시하여 완료되었음을 연출하여라.
  ```
