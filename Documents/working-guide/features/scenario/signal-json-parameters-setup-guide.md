# 시나리오 JSON 파라미터 시그널 설정 안내

## 언제 사용하나요?

기존 시그널은 “행동이 일어났음”만 판정합니다. 어떤 환자를 선택했는지, 점수나 측정값이 무엇인지처럼 행동의 세부 정보를 세션 로그와 운영 도구에서 확인해야 할 때 JSON 파라미터를 사용합니다.

## 게임플레이 코드 작성

행동이 확정되는 지점에서 다음처럼 호출합니다.

```csharp
ScenarioInteractionSignals.Raise(
  "patient_assessed",
  "{\"patient\":\"patient_b\",\"triageLevel\":2}");
```

문자열은 반드시 유효한 JSON이어야 합니다. 입력값을 조합할 때는 따옴표와 역슬래시를 안전하게 처리하십시오. 유효하지 않은 JSON은 서버가 거부하며 시나리오 게이트도 통과하지 않습니다.

## Unity Editor에서 확인하는 방법

1. 서버 또는 호스트로 인게임 세션을 시작합니다.
2. 파라미터 시그널을 발생시키는 상호작용을 수행합니다.
3. 채팅에 `/signal get patient_assessed`를 입력해 전체 최신 값을 확인합니다.
4. 특정 참가자를 확인하려면 `/signal player 참가자표시이름 patient_assessed`를 사용합니다.
5. 재시험 전에 `/signal flush`를 입력하면 파라미터 값만 초기화됩니다. 시나리오 게이트용 완료 시그널까지 초기화하려면 시나리오를 새로 시작하십시오.

## 주의 사항

- 시나리오 시작 시 저장값은 자동으로 비워집니다.
- 늦게 접속한 참가자는 서버가 보관하는 마지막 값을 자동으로 받습니다.
- 같은 시그널을 여러 플레이어가 발생시키면 기본 조회는 가장 마지막 값을 보여줍니다. 플레이어별 값을 보려면 `/signal player`를 사용하십시오.
- 현재 Validator JSON은 파라미터 안의 수치를 비교하지 않습니다. 파라미터는 기록·운영 조회·후속 시스템 통합을 위한 데이터이며, 비교형 시나리오 조건은 별도 기능으로 추가해야 합니다.
