# 시나리오 그래프 작성

시나리오 그래프를 작성하고 수정하는 데 있어서는 세 가지 방법을 사용합니다.  

1. AI 사용
    - Markdown 문서를 이용해 시나리오 그래프를 새로 작성
    - 시나리오를 이용한 게임 시스템에 버그가 있거나 새 기능이 필요할 때, 시스템 코드와 함께 수정하기 위해서 사용
    - 시나리오의 수정이 광범위함
2. 유니티 에디터에서 Scenario Graph Editor를 이용해 시나리오 그래프를 작성
    - 시나리오의 재생 흐름을 확인하면서 작성/수정
    - 간단한 시나리오 수정
    - 시나리오의 흐름을 시각적으로 확인하면서 작성/수정
3. 시나리오 그래프의 `.scenario.json` 파일을 직접 편집
    - 간단한 시나리오 수정
    - Visual Studio Code 상에서 수정

## AI 사용

![](./_static/authoring-scenario-graph/claude-code-graph-debug.png)  

시나리오의 원본 기획서인 Markdown 문서로부터 새롭게 시나리오 그래프를 작성하려고 하거나, 시나리오 그래프가 나타내는 재생 흐름대로 재생되지 않을 때(버그가 의심될 때), 게임 시스템과 함께 시나리오 그래프를 수정해야 할 때 주로 이 방법을 사용합니다.  

<br />

![](./_static/authoring-scenario-graph/codex-acting-npc.png)  

혹은 의도하는 바를 자세하게 작성하여, 원하는 상황을 시나리오 그래프로 표현할 수 있는지를 확인, 시나리오 그래프를 수정하도록 지시할 수도 있습니다.  

<br />

![](./_static/authoring-scenario-graph/codex-debug-error.png)  

만약 유니티에서 오류가 발생하여 게임이 제대로 실행되지 않는다면, 별다른 코멘트 없이 오류 메시지를 그대로 전달하여 문제를 수정할 수 있습니다.  

## 유니티 에디터에서 Scenario Graph Editor 사용

![](./_static/authoring-scenario-graph/scen-ingame.png)  

![](./_static/authoring-scenario-graph/scen-nowplaying.png)  

이 방법에서는 인게임에서 시나리오를 직접 플레이하면서 수정할 수 있습니다. 

이 때 실제로 인게임에서는 필요하지만 시나리오 데이터/코드 상에서는 미구현되거나 부족한 내용이 무엇인지 확인하거나, 시나리오 노드가 어떤 순서로 처리되었는지 확인하면서 어떤 노드에서 문제가 발생했는지 판단할 수 있습니다.  

<br />

> [!WARNING]  
> 간혹 저장을 시도할 때, 시나리오 그래프 노드의 검증이 실패했다는 경고가 나타날 수 있습니다. 이 때는 코드 상에서 문제가 발생했을 가능성이 높습니다.  
> 이 때는 저장을 취소하고, 다른 이름으로 시나리오를 저장(오류를 무시하고 저장), 커밋을 수행한 후, 아래와 같이 AI에게 문제 상황을 해결하도록 지시하세요.  

![](./_static/authoring-scenario-graph/codex-scen-validation-err.png)  

_AI는 유니티 에디터의 전체 로그를 로드하여 문제 상황을 파악할 수 있으므로, 위와 같이 오류 메시지 일부를 복사-붙여넣기하여 지시문을 작성할 수도 있습니다._  

## 시나리오 그래프의 `.scenario.json` 파일 직접 편집

어떤 옵션의 On/Off 설정, 구체적인 수치나 텍스트를 수정할 때는 텍스트 에디터에서 직접 값을 편집할 수도 있습니다. 특히 AI를 사용하여 시나리오 그래프를 수정하는 도중인 경우에는, 다른 두 방법(AI 사용<sup>1</sup>, Scenario Graph Editor<sup>2</sup>)은 사용하기 어려울 수 있습니다.

<sup>1</sup>: AI를 사용하여 수정 작업을 수행하는 도중에 다른 AI 세션에게 새롭게 작업을 지시할 수 있습니다. AI는 지시문이 내려진 상황을 기준으로 작업을 시작하므로, AI의 작업 범위를 정확하게 정하지 않는다면 두 AI가 서로의 작업 내용을 덮어쓰기할 수 있습니다.  

<sup>2</sup>: AI를 사용하여 시나리오 그래프를 수정하는 도중에는 목표를 달성하기 위해 AI가 코드를 변경할 수도 있습니다. 유니티는 코드가 변경되면 자동으로 유니티를 새로고침하므로 시나리오 그래프의 작업 내용이 사라질 수 있습니다.  

![](./_static/authoring-scenario-graph/code-edit-manually.png)  

이 때는 직접 `.scenario.json` 파일을 열어 원하는 부분을 수정하는 편이 나을 수 있습니다.  

<br />

![](./_static/authoring-scenario-graph/claude-noticed-manual-changed.png)  

> [!WARNING]  
> AI가 작업 중에 직접 수정하는 과정에서, AI가 지시문 실행 시점과 차이를 식별하게되어 작업이 평소보다 늦어질 수 있습니다. 상황에 따라 판단하여 작업하는 편이 좋습니다.
