# Sync Progress

_작업 내용을 공유하거나 동기화하기_

#### SourceTree, 작업 상황을 내려받기

1. Fetch: 상단의 "페치" 버튼을 클릭하여 최신 변경 사항이 있는지 확인합니다.
2. Pull: 변경 사항이 있으면 "풀" 버튼을 클릭하여 로컬 저장소에 내려받습니다.

#### SourceTree, 작업 상황을 올리기

1. 커밋 버튼을 선택하여 커밋 화면으로 전환합니다.
2. 대기중인 변경 사항 중 업로드할 항목을 선택(일반적으로 전부 선택)합니다.
3. 하단의 넓은 텍스트 필드에 변경사항에 대한 설명을 짧게 작성합니다.
    - 첫째 줄은 항상 변경사항에 대한 짧은 요약*이 서술되어야 합니다.
4. 커밋 버튼을 클릭하여 커밋을 완료합니다.
5. 상단의 "푸시" 버튼을 클릭하여 원격 저장소에 변경 사항을 업로드합니다.

\* 요약은 다음 규칙을 따라주세요: `(작업 유형): (한 문장으로 정리)`

![commits](./_static/sync-progress__commit-history.png)

작업 유형은 아래 중 하나여야 합니다:
- `fix` : 버그 수정
- `feat` : 새로운 기능 추가
- `docs` : 문서 수정
- `style` : 코드 스타일 변경 (기능 변경 없음)
- `refactor` : 코드 리팩토링 (기능 변경 없음)
- `test` : 테스트 코드 추가/수정
- `chore` : 기타 변경 사항 (빌드 프로세스 수정 등)
- 예시: `feat: 아이템 등록 시스템 추가`
