# Agents

AI 프롬프트(지시문) 템플릿 및 결과 자료

- [Actually Used](./Actually%20Used) : 실제로 AI에게 제공되어 사용된 프롬프트 및 결과물
- [Examples](./Examples) : 프롬프트 템플릿 예시
- [Templates](./Templates) : 프롬프트 템플릿 원본
- [Proposals](./Proposals) : AI가 구현의 부족함을 확인하고 작성한 기능 제안서

## 실제 사용 방법

각 작업에 필요한 프롬프트를 Templates 폴더에서 찾아, 적절히 수정한 뒤 AI에게 제공하여 작업을 수행합니다. 작업이 완료되면 결과물을 검토하고, 필요한 경우 추가 질문을 통해 보완합니다. 최종 결과물은 프로젝트에 커밋합니다.

만약 원하는 템플릿이 없다면, 이미 존재하는 템플릿을 참고하여 새로 작성하여 Templates 폴더에 추가합니다.
