> 상태: **반영 완료(done, 2026-08-07)**. `ScenarioGraphEditor.AutoLayoutNodes`의 `DisplayProgressBar` 단계별 진행 팝업과 `try/finally` 정리, 사이드카 없을 때만 자동 배치 조건이 구현됨.

### 개요

Scenario Graph Editor가 에디터 사이드카 없는 그래프를 자동 배치하는 동안 단계별 진행 팝업을 표시한다.

### 해결하려는 문제 상황

대규모 그래프의 자동 배치는 Unity 메인 스레드에서 동기적으로 실행된다. 기존 UI에는 작업 상태가 표시되지 않아 사용자가 에디터가 멈췄다고 판단할 수 있다.

### 사용자 경험 목표

- 자동 배치가 실행 중이라는 사실을 즉시 알 수 있다.
- 현재 처리 단계와 전체 진행률을 확인할 수 있다.
- 정상 완료와 예외 발생 모두에서 팝업이 남지 않는다.

### 제안

- `.scenario.editor.json`이 없는 파일을 열 때만 진행 팝업을 표시한다.
- `EditorUtility.DisplayProgressBar`로 연결 분석, 순환 정규화, 레이어 계산, 긴 간선 분할, 교차 최소화, 좌표 적용 단계를 표시한다.
- 교차 최소화는 각 반복 완료 시 진행률을 갱신한다.
- 전체 자동 배치를 `try/finally`로 감싸 `EditorUtility.ClearProgressBar`를 보장한다.

### 자세한 달성 목표

- 사이드카 위치를 복원하는 일반 로드에는 팝업을 표시하지 않는다.
- 자동 배치 알고리즘의 결과와 저장 형식은 변경하지 않는다.
- 진행 UI 갱신은 알고리즘 단계 경계에서만 수행해 추가 비용을 제한한다.

### 문서화

Scenario Graph Editor README의 자동 레이아웃 설명에 진행 팝업의 표시 조건과 단계를 추가한다.

### 가용성과 테스트

- Unity Editor 어셈블리 컴파일을 확인한다.
- 사이드카 없음, 사이드카 있음, 자동 배치 예외의 세 경로에서 팝업 수명주기를 확인한다.

### 구현에 성공한 구현체는 무엇이며, 성공 여부는 어떻게 측정할 수 있나요?

- 사이드카 없는 대형 그래프 로드 시 자동 배치 시작부터 완료까지 진행 팝업이 보인다.
- 사이드카가 있는 그래프에는 팝업이 나타나지 않는다.
- 자동 배치가 실패해도 진행 팝업이 닫히고 기존 로드 오류 처리가 계속 동작한다.

### 링크, 참고사항

- Unity `EditorUtility.DisplayProgressBar`
- Unity `EditorUtility.ClearProgressBar`
