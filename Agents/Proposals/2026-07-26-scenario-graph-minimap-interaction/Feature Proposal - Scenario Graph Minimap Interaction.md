### 개요

Scenario Graph Editor 미니맵의 이동, 크기 조절, 뷰포트 탐색 기능을 활성화하고 기본 상태 복원 메뉴를 제공한다.

### 해결하려는 문제 상황

기존 미니맵은 `anchored = true`로 생성되어 위치가 고정되며, 사용자가 작업 공간에 맞게 위치와 크기를 조절하거나 쉽게 초기화할 수 없었다.

### 사용자 경험 목표

- 미니맵 헤더를 잡아 원하는 위치로 옮길 수 있다.
- 테두리와 모서리를 드래그해 크기를 조절할 수 있다.
- 미니맵 본문을 클릭·드래그해 그래프 뷰포트를 이동할 수 있다.
- 잘못 배치하거나 크기를 바꾼 미니맵을 메뉴에서 즉시 초기화할 수 있다.

### 제안

- 실험적 `GraphView.MiniMap`을 사용하지 않고 `ScenarioGraphMiniMap`을 독립 `VisualElement`로 구현한다.
- 노드, 엣지, 현재 viewport 표시를 `Painter2D`로 직접 렌더링한다.
- 그래프 좌표는 단일 균일 배율로 투영해 종횡비를 유지하고, 남는 축은 가운데 정렬된 여백으로 남긴다.
- 현재 viewport는 반투명 흰색 사각형과 더 불투명한 얇은 흰색 테두리로 표시한다.
- 미니맵 외곽에는 둥근 모서리를 적용하고, 헤더 텍스트와 구분선은 흰색 계열로 정렬한다.
- 단일 로컬 좌표계에서 헤더 이동, 4개 변·4개 모서리 리사이즈, 본문 viewport 탐색을 판정한다.
- 리사이즈 시작 사각형을 별도 필드에 보관하고 포인터의 누적 이동량으로 계산해 레이아웃 갱신 시점에 따른 크기 급변을 막는다.
- 리사이즈 hover 시 조작 대상 테두리를 강조한다.
- 미니맵 전체에 `overflow: hidden`을 적용해 현재 viewport 표시가 본체 밖으로 나오지 않게 한다.
- 기본 사각형은 `(5, 5, 175, 135)`, 최대 크기는 `800×600`으로 설정한다.
- 상단 `View` 메뉴에 `Reset Minimap`을 추가한다.
- Reset은 기본 사각형 복원, repaint 및 최상단 표시를 수행한다.
- 미니맵 사각형은 Open Recent 캐시의 파일별 `MiniMaps` 항목에 저장하고 해당 파일을 다시 열 때 복원한다.

### 자세한 달성 목표

- 미니맵 렌더링과 모든 입력은 Unity GraphView MiniMap의 내부 레이아웃 및 capability에 의존하지 않는다.
- 그래프 노드와 에디터 사이드카 데이터는 변경하지 않는다.
- Reset은 현재 Editor 창의 미니맵 UI 상태에만 영향을 준다.

### 문서화

Scenario Graph Editor README에 미니맵 상호작용과 Reset 메뉴를 설명한다.

### 가용성과 테스트

- Unity Editor 어셈블리 컴파일을 확인한다.
- 헤더 드래그, 각 테두리 리사이즈, 본문 클릭·드래그, Reset 동작을 확인한다.

### 구현에 성공한 구현체는 무엇이며, 성공 여부는 어떻게 측정할 수 있나요?

- 네 가지 사용자 동작이 Graph 탭에서 정상 작동한다.
- Reset 후 미니맵이 좌상단 `(5, 5)`와 `175×135` 크기로 복원된다.

### 링크, 참고사항

- Unity GraphView `MiniMap`
- Unity GraphView `Capabilities.Movable`
- Unity GraphView `Capabilities.Resizable`
