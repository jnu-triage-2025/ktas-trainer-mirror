### 개요

Scenario Graph Authoring의 자동 배치를 Sugiyama 계층형 그래프 레이아웃으로 교체한다. 좌→우 진행 레이어를 유지하면서 교차를 줄이고, 연결된 노드를 가능한 한 같은 가로 행에 배치해 시나리오의 주 흐름을 빠르게 읽을 수 있게 한다.

### 해결하려는 문제 상황

기존 배치기는 BFS 깊이별 노드를 단순 적층하고, 긴 그래프를 뱀 형태로 접었다. 따라서 단일 순차 경로도 세로로 흔들리고, 분기와 합류가 많은 그래프에서 연결선 교차와 역방향 흐름이 쉽게 발생했다.

### 사용자 경험 목표

- 순차 연결 `A → B → C`는 가급적 같은 `y` 좌표에서 직선으로 보인다.
- 분기·합류만 필요한 최소한의 세로 공간을 사용한다.
- 순환 연결은 보존하되 주 진행 경로의 좌→우 순서를 방해하지 않는다.
- 같은 입력 그래프는 항상 같은 배치 결과를 만든다.

### 제안

`ScenarioGraphAuthoringWindow.AutoLayoutNodes`를 다음 단계로 구성한다.

1. 참조 가능한 출력 간선을 수집한다. `Next`, Choice, Parallel 및 Quiz 정답/오답 분기를 포함한다.
2. DFS에서 현재 탐색 경로로 되돌아가는 feedback edge를 레이어 제약에서 제외해 DAG를 만든다.
3. 위상 순서의 longest-path 방식으로 레이어(x)를 지정해 모든 순방향 연결이 오른쪽을 향하게 한다.
4. 긴 간선은 중간 레이어 dummy vertex 체인으로 정규화한다.
5. 전·후방 median sweep으로 레이어 내부 순서를 반복 조정해 교차를 줄인다.
6. 이웃 좌표의 median과 충돌 해소를 반복해 부모를 자식 묶음의 세로 중심에 정렬한다.
7. 분기 포트 순서를 동점 해소 제약으로 사용한다. sweep과 인접 교환은 교차 수를 1순위, 총 세로 간선 변위를 2순위로 비교해 수평 연결이 더 많은 최선의 순서를 보존한다.

### 자세한 달성 목표

- 노드 위치만 바꾸며 시나리오 JSON 데이터·런타임 실행·수동으로 저장한 에디터 좌표에는 영향을 주지 않는다.
- `.scenario.editor.json`이 없는 그래프를 열 때만 자동 배치가 적용된다.
- 레이어의 노드 개수는 제한하지 않는다. 레이어 간격 420px, 행 간격 240px, 교차 최소화 6회, 좌표 정렬 4회를 기본값으로 둔다.

### 문서화

- ScenarioGraphEditor 사용자 설명서의 자동 레이아웃 설명을 새 알고리즘과 동작 범위에 맞게 갱신한다.
- 이 제안서와 example implementation을 변경 근거 및 구현 참조로 보관한다.

### 가용성과 테스트

- 위험: 순환·분기·합류에서 배치 결과가 예상보다 넓어질 수 있다. feedback edge는 레이어링에서 제외해 이를 제한한다.
- 정적 검토: 모든 참조 타입(일반/Choice/Parallel/Quiz)을 수집하는지 확인한다.
- Unity batchmode 컴파일로 Editor 어셈블리 컴파일을 확인한다. 라이선스 또는 환경 DB가 잠긴 경우에는 해당 외부 환경 문제를 별도로 기록한다.

### 구현에 성공한 구현체는 무엇이며, 성공 여부는 어떻게 측정할 수 있나요?

- 순차 그래프에서 각 연결 노드의 `y` 값이 일치한다.
- 분기와 합류가 있는 DAG에서 모든 순방향 간선의 대상 레이어가 원본보다 오른쪽이다.
- 순환이 있는 그래프도 예외 없이 배치되며 모든 노드가 위치를 가진다.
- 같은 입력으로 다시 열었을 때 좌표가 결정론적으로 동일하다.
