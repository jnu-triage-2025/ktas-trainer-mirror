# Fluent Korean 출력 스타일

본 프로젝트는 `Tools/fluent-korean/` 서브모듈의 `fluent-korean` 출력 스타일을 사용한다. 이 도구는 기존 초안을 사후 윤문하는 도구가 아니라, 한국어 산출물을 작성하기 전과 사용자에게 전달하기 직전에 적용하는 작성 지침이다.

## 시작 절차

1. 한국어 사용자 응답, 문서, 이슈 본문 또는 텍스트 콘텐츠를 작성할 때 `Tools/fluent-korean/plugins/fluent-korean/output-styles/fluent-korean.md` 전문을 읽는다.
2. 해당 지침을 작성 과정과 최종 검토에 적용한다. 도구 실행, 경로 점수화, 변경률 게이트, 별도 윤문 단계는 사용하지 않는다.
3. 코딩 작업에서는 코딩 지침을 유지하는 `fluent-korean.md`만 사용한다. 코드 변경 없이 대화·문서 작성만 수행하는 환경에서는 필요에 따라 `fluent-korean-not-coding.md`를 사용한다.

## 적용 범위

- 사용자에게 전달하는 한국어 응답과 보고
- 한글 문서, 이슈 본문, 기능 제안서, Setup Guide, Documented Reference
- 코드에 속하지 않는 텍스트 콘텐츠

## 적용 제외

- 코드 주석, 변수명, 로그 문자열, 커밋 메시지 등 코드 관례를 따라야 하는 텍스트
- 인용문과 코드 블록
- 원어를 유지해야 하는 고유 명사와 기술 용어

## 핵심 원칙

1. 조사와 어미를 생략하지 않고, 문장을 서술어와 종결어미로 완결한다.
2. 맥락을 생략한 짧은 명사 나열이나 비유적 표현보다 정확하고 통용되는 어휘를 선택한다.
3. 기술 용어는 한국어 번역어 또는 음차가 널리 쓰이는 경우에만 사용하고, 그렇지 않으면 원어를 유지한다.
4. 사용자의 어조를 기계적으로 모방하지 않고, 의미가 분명하고 읽기 쉬운 한국어를 유지한다.

## 도구를 사용할 수 없는 경우

서브모듈이 초기화되지 않았거나 출력 스타일 파일을 읽을 수 없으면, 작업을 중단하지 않는다. 문맥을 충분히 갖춘 완결된 한국어 문장으로 작성하고, 사용자에게 별도 경고 문구를 넣지 않는다.
