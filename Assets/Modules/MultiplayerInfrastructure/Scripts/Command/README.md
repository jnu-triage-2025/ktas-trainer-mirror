# Command Module

## 플레이어 지정 방법

커맨드가 플레이어를 인자로 받을 때에는 모두 `PlayerTargetResolver`를 거치므로, 아래에 정리한 표기법을 모든 커맨드에서 동일하게 사용할 수 있습니다.

| 표기 | 의미 |
| :-- | :-- |
| `@a`, `@p`, `@r`, `@s`, `@e`, `@n` | 대상 선택자입니다. `@a[tag=doctor,distance=..10]`처럼 인자를 붙일 수 있습니다. |
| `@self`, `self`, `me` | 커맨드를 실행한 본인을 가리킵니다. |
| `id:<uuid>`, `uuid:`, `user:` | 사용자 식별자로 찾습니다. 앞부분만 입력해도 후보가 하나로 좁혀지면 통과합니다. |
| `name:<표시 이름>`, `player:`, `displayname:` | 표시 이름으로 찾습니다. |
| `fish:<번호>`, `client:`, `clientid:`, `conn:` | FishNet 연결 번호로 찾습니다. |
| `entity:<식별자>` | 레지스트리에 등록된 플레이어 엔티티 식별자로 찾습니다. |
| 접두사가 없는 문자열 | 식별자, 표시 이름, 연결 번호, 엔티티 식별자, 부분 일치의 순서로 찾습니다. |

표시 이름에 공백이 들어 있다면 `"김철수 학생"`처럼 큰따옴표로 감싸서 입력합니다. 감싼 따옴표는 해석 단계에서 제거되기 때문에, `name:"김철수 학생"`처럼 접두사와 함께 사용해도 정상적으로 처리됩니다.

## 이름 일치 규칙

문자열과 플레이어를 대응시키는 규칙은 `Session/PlayerNameQuery`가 담당합니다. 아래 단계를 순서대로 평가하고, 후보가 처음으로 발견된 단계에서 평가를 중단합니다.

1. 식별자 완전 일치
2. 표시 이름 완전 일치(대소문자를 구분하지 않습니다.)
3. 공백과 구두점을 제거한 표시 이름 일치
4. 식별자 앞부분 일치(네 글자 이상을 입력해야 합니다.)
5. 표시 이름 앞부분 일치
6. 공백과 구두점을 제거한 표시 이름 앞부분 일치
7. 표시 이름 부분 문자열 일치
8. 공백과 구두점을 제거한 표시 이름 부분 문자열 일치

1번부터 3번까지의 완전 일치 단계에서는 동명이인이 존재하더라도 식별자 순서에 따라 한 명을 확정합니다. 4번부터 8번까지의 추측성 단계에서는 후보가 둘 이상이면 확정하지 않고, 후보 목록을 포함한 오류 메시지를 반환합니다.

## 해석 결과의 종류

커맨드가 필요로 하는 대상의 형태에 따라 다음 함수들을 사용합니다.

| 함수 | 반환 대상 |
| :-- | :-- |
| `TryResolve`, `TryResolveSingle` | `UserDescriptor`입니다. 세션 정보만 필요한 커맨드가 사용합니다. |
| `TryResolveConnections`, `TryResolveSingleConnection` | `NetworkConnection`입니다. RPC 전송 대상이 필요한 커맨드가 사용합니다. |
| `TryResolveControllers`, `TryResolveSingleController` | `PlayerController`입니다. 위치나 인벤토리를 다루는 커맨드가 사용합니다. |

`Single` 계열 함수는 대상이 둘 이상으로 해석되면 오류를 반환하므로, 여러 명에게 동시에 적용해도 되는 커맨드에서는 복수형 함수를 사용해야 합니다.

## 자동 완성 후보 목록

플레이어를 지정하는 인수 자리에서 Tab을 누르면, 접속 중인 플레이어마다 표시 이름과 `id:` 토큰, `fish:` 토큰을 함께 제시하고 마지막에 대상 선택자를 덧붙입니다. 후보 목록을 만드는 함수는 `PlayerTargetResolver.CollectTokenSuggestions`이며, 각 후보 오른쪽에 표시할 설명은 `PlayerTargetResolver.DescribeToken`이 돌려줍니다.

| 후보 형태 | 오른쪽에 표시하는 설명 |
| :-- | :-- |
| `Bob`, `"김철수 학생"` | 표시하지 않습니다. 후보 자체가 이름이기 때문입니다. |
| `id:<uuid>` | 그 식별자를 가진 플레이어의 표시 이름 |
| `fish:<번호>` | 그 연결 번호를 쓰는 플레이어의 표시 이름 |
| `@s`, `@a`, `@p`, `@r`, `@n`, `@e` | 선택자의 뜻(`yourself`, `all players` 등) |

표시 이름에 공백이 있으면 후보를 큰따옴표로 감싸서 제시합니다. 따옴표를 입력하지 않고 이름의 앞부분만 쳐도 후보가 걸리며, 따옴표로 감싼 낱말 안에 커서가 있으면 그 낱말 전체를 한 토큰으로 보고 교체합니다. 인수 위치를 셀 때에도 따옴표로 감싼 구간을 한 인수로 취급하므로, 이름에 공백이 있어도 다음 인수의 후보가 어긋나지 않습니다.

일반 채팅 입력에서는 문장에 그대로 넣을 수 있는 표시 이름만 제안합니다. `id:`나 선택자는 커맨드 인수 자리에서만 제안합니다.
