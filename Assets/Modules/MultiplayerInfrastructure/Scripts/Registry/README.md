레지스트리는 게임 내에서 전역적으로 접근 가능한 데이터를 저장하고 관리하는 역할을 합니다.

특히 각 인스턴스를 참조해야 할 때, 싱글톤 유니티 오브젝트가 의도되지 않았다면 레지스트리에 객체를 등록하여 참조 핸들을 추가하는 것이 권장됩니다. 이렇게 함으로써 유니티의 게임 오브젝트가 생성되는 데 투입되는 비용을 줄이고, 코드를 조금 더 덜 복잡하게 작성하도록 합니다.  

되도록 레지스트리는 `Get<T>()`, `Register<T>(T instance)`, `Unregister<T>(T instance)` 메서드를 통해 접근하는 것이 의도됩니다. 하지만 모든 레지스트리가 그렇게 작동할 수 있는 것은 아니기 때문에, 인터페이스로 제약이 정의되지는 않았습니다.

## 구현에 관련하여

대부분의 레지스트리는 MonoBehaviour를 상속하지 않고, 모든 필드를 static으로 구현하는 것이 의도됩니다. 이렇게 함으로서 다른 유니티 오브젝트에서 Awake() 과정 중에 레지스트리에 접근할 수 있도록 합니다.
