# UI Definitions and Controls

인게임에서의 UI 정의와 그 제어를 위한 제어 스크립트에 관한 구현입니다.

## UI 제어 호출하기

여기서 정의된 UI는 싱글톤 패턴이 의도되지 않았습니다. 실제로는 그러한 시나리오를 고려하는 것이 적절하지 않다고 하더라도, 같은 UI를 여러 인스턴스로 호출할 수도 있습니다. 따라서 컨트롤러 외부에서 UI 컨트롤을 호출하려면 참조할 수 있는 핸들이 필요합니다.  

모든 UI 컨트롤러는 `UIControlRegistry`에 개별 필드를 등록하는 것이 의도됩니다. 이 레지스트리는 UI 컨트롤러의 인스턴스를 보유하고 있으며, 다른 스크립트에서 해당 컨트롤러에 접근할 수 있도록 합니다. 관련해 최소한의 제약 사항으로 모든 컨트롤러는 `UIControllerABC`를 상속해야 합니다. `UIControllerABC`는 `UIControlRegistry` 등록시 호출하는 것이 의도되는 `Register()` 메서드가 정의되어 있고, `Awake()` 사이클에서 호출되도는 것이 의도됩니다.  

## Focus가 해제되어야 하는 UI의 경우

항상 표시되는 HUD 인터페이스가 아니라, 특정한 상황에서 마우스 포커스가 풀리고 UI가 표시되어야 하는 경우(메뉴, 채팅 등), 시스템은 마우스와 카메라, 커서 등에서 포커스를 해제하거나 설정하는 처리가 요구됩니다.  

이 경우에는 IUIOverlay 인터페이스를 구현하는 것이 의도됩니다.
